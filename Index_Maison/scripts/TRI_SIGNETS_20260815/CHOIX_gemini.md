# CHOIX gemini (provider Google Gemini, 2.3s)

1. N° 4 — Magnitude (agent 100% local) correspond directement à notre contrainte hub local 11435 sans frais.
2. N° 12 — Brain.md (mémoire persistante en Markdown) optimise notre gestion de contexte sans alourdir la RAM.
3. N° 44 — Kimi K3 (très gros modèle tournant sur CPU avec 8 Go de RAM) résout notre contrainte matérielle critique.
4. N° 50 — Les 3 schémas de workflow d'Anthropic (séquentiel/parallèle) structurent parfaitement l'architecture de Cortana.
5. N° 53 — TencentDB Agent Memory offre une solution idéale pour la persistance des décisions et de la mémoire des agents.
6. N° 70 — spec-kit (spécifications avant code) évite aux agents de deviner et fiabilise le développement du prototype.
7. N° 142 — BitNet (LLM 100B sur simple CPU sans GPU) s'aligne parfaitement avec notre configuration technique locale.
8. N° 169 — Les bibliothèques Python gratuites de données de marché alimentent directement le moteur de trading paper MEXC.
9. N° 189 — TradingAgents (analyse de marché par agents open-source) apporte une brique clé pour notre stratégie Hulk dip&rip.
10. N° 192 — L'utilisation de fichiers de suivi au lieu de recharger l'historique réduit drastiquement les tokens consommés.

Sélection axée sur la compatibilité matérielle stricte (8 Go RAM, local 11435), l'optimisation des tokens et l'architecture des agents de trading (Hulk & Cortana) sans API payante.
