## CE QUE FAIT LE PROJET
- **Overledger** = OS d'interopérabilité multi-DLT : connecte les blockchains entre elles ET aux systèmes d'entreprise existants
- Le token QNT = **licence économique** : les entreprises DOIVENT payer QNT pour accéder aux APIs Overledger (gateways, licences annuelles)
- Utilité directe : chaque accès enterprise = achat/burn QNT (le meilleur cas d'usage token parmi les L1 enterprise)
