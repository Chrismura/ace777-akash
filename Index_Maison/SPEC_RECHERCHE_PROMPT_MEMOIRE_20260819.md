# MISSION RECHERCHE — « le prompt et la mémoire d'ensemble : état de l'art 2026 »

Contexte : ACE777 est un organisme autonome — un hub de providers IA gratuits
+ une « famille » d'agents à rôles (analyste, juge, codeur, gardienne…) + un
cockpit + une mémoire Obsidian. On veut passer à l'avant-garde sur 2 fronts :
(1) le prompt — parce que le PERSONNAGE compte plus que le modèle ;
(2) la mémoire — pour que chaque IA ait la vision d'ensemble du système.

Réponds aux 4 questions, chacune avec des sources réelles ET datées :

1. COMMENT améliorer les prompts d'agents autonomes ?
   (état de l'art 2026 : role isolation, context engineering,
   failure-mode instructions, structured output… — techniques concrètes)

2. QUELLE est la meilleure solution pour donner à une IA une
   « vision d'ensemble mémorielle » (état + historique + leçons + contexte) ?
   Compare les approches : file-over-agent / brain.md, RAG, mémoire vectorielle,
   context engineering, mémoire long-terme… Donne un classement + le pourquoi.

3. EXISTE-t-il d'autres solutions / approches que nous n'avons pas citées ?
   (ce qu'on rate, ce qui monte en ce moment)

4. CRITIQUE et complète nos 3 pistes maison :
   (a) un registre unique de personnages (identité + méthode + niveau
       d'intelligence requis) ;
   (b) une boucle de justesse du prompt (mesurer → améliorer, le prompt
       comme paramètre optimisable) ;
   (c) un « sniffer » de veille avant-garde (sources Anthropic/arXiv/…
       qui alimentent le registre).
   Dis ce qui est juste, ce qui manque, ce qui est risqué.

FORMAT DE SORTIE : par question → 3-5 points concrets + source (lien + date si
connue). Si tu cites de mémoire sans être sûr de la date, dis-le honnêtement
(« de mémoire, à vérifier »). Termine par un TOP 3 d'actions pour ACE777.
