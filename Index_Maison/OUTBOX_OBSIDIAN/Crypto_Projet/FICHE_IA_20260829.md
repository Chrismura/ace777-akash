## 3. 🎯 LE CADRE DE DÉCISION D'INVESTISSEMENT (LE STANDARD MAISON)

> **C'est LA section qui fait de nous un cabinet, pas un groupe Telegram.** Toute
> décision d'entrer/sortir/tenir une position DOIT passer par ce cadre. Ce
> document sert de preuve : on arrive à la source ou rien, et on encadre.

### Étape 0 — La donnée doit être VRAIE (la règle des 2 sources)
- **Jamais de décision sur une donnée non croisée.** Prix : écart > 5 % vs
  MEXC/Binance = FAIL bloquant (croisement externe). 
- Leçon QAIT : un `--resume` copie l'ancien CSV → un trade apparaît dans 18
  fichiers → **−49,91 $ faux devenu −22,15 $ réel**. Toujours `--all` + dédup.

### Étape 1 — Le projet (dossier de banque d'affaires)
Pour chaque actif, une fiche projet avec :
1. **La société réelle** : qui est derrière ? société cotée ? (ex : QAIT =
   SEALCOIN, filiale de WISeKey, NASDAQ:WKEY + SIX:WIHN — une VRAIE société
   suisse de cybersécurité, pas un anonymat)
2. **La thèse** : que fait le projet, quel problème résout-il, quel narratif ?
3. **Le brut (sources primaires)** : dépôt SEC, site officiel, communiqués —
   jamais une synthèse de seconde main
4. **Le tokenomics** : supply totale, % verrouillé, vesting, unlocks (le risque
   majeur des micro-caps)
5. **La géographie du trading** : quelle session anime le carnet ? (QAIT =
   100 % des pics la nuit asiatique)

### Étape 2 — Le marché (nos données, pas les prédictions)
- Profil murs (spread, profondeur, spoof) — via observer_murs
- Signal 3 (squeeze/vacuuming), SAPI (poussière), essaim (coordination)
- Corrélations au panier et au marché (QAIT : anti-BTC −0,21 mais POMPE-PIÈGE −0,45)

### Étape 3 — Le risque (TOUJOURS chiffré)
- Perte max en scénario de base / stressé
- Spread vs stop : si spread > stop, on ne trade pas (QAIT 63 bps = stop serré suicidaire)
- Volatilité (range, vol_spike) : QAIT range 231 %, vol_spike 13×
- Tokenomics : dilution aux unlocks

### Étape 4 — La décision (explicite, datée, signée)
| Type | Critère | QAIT (exemple) |
|---|---|---|
| **TRADER** (scalping) | Spread fin + liquidité + stop viable | ❌ spread 63 bps, murs 1 100 $ |
| **TENIR (bag)** | Thèse long terme + société réelle | ⚠️ poker sur thèse DePIN, pas un trade |
| **OBSERVER** | Données capturées, décision différée | ✅ RIZE, SOL, essaim en obs |
| **EXCLURE** | Non-deepdive, profil dangereux | ADA (éjectée), exclues prudence |

### Étape 5 — La révision (rien n'est statique)
- **14 jours de réserve** : les leaders changent, le marché change — un signal
  valable aujourd'hui peut ne plus l'être demain. On valide tant que les chiffres
  le montrent.
- Chaque décision journalisée (date, raison, données, sources) dans ces fiches.

## 7. 📚 LES DÉCOUVERTES TECHNIQUES (réutilisables)

- **Dédup des trades** : un `--resume` copie l'ancien CSV dans le nouveau → un même
  trade apparaît dans 18 fichiers ! TOUJOURS analyser avec `--all` + dédup par timestamp
  (leçon QAIT : −49,91 $ faux → −22,15 $ réel).
- **Règle des 2 sources** : avant toute décision importante, croiser le chiffre clé
  avec une source externe. Le croisement le fait pour les prix (5 %).
- **Murs vs prix** : les murs changent naturellement d'un facteur 10+ sur les small
  caps → contrôle d'ordre de grandeur (x0.05-x20), jamais un contrôle fin.
- **mempool.space peut tomber** : fallback blockstream.info en place (fees).
- **Écriture atomique** : .tmp + os.replace partout (fin des fichiers tronqués).
- **Round 3 géostratégie (29/08)** : les 3 IA corroborent indépendamment les mêmes
  acteurs physiques (TLN, VST, CEG, TSM, Thales, Cameco, Securitize/BUIDL) — la thèse
