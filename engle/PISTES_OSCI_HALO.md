# Pistes (parenthèse climat → bot) — ne pas confondre avec le KPI

**Rôle :** carte conceptuelle. **Pas** la todo du jour.  
**KPI session :** fills ALPHA ≥ ~29 $ (`SESSION_AMELIORATION_GROK.md`).

## Analogies utiles (Gemini / article climat)

| Idée | Lecture bot (NUAGE) | Priorité |
|------|---------------------|----------|
| Oscillateur à retardement | tension / shock : force + **délai** avant inversion (déjà K3 hold) | proche — déjà en stack |
| Kelvin (rapide, local) | micro-wicks / shock court → souvent net négatif | à **filtrer**, pas chasser |
| Rossby (lent, grand) | régime / tempête multi-minutes → là où ALPHA peut faire +20–30 $ | **cibler** |
| Swarm intelligence | BETA scout + ALPHA hunter = rôles, pas monolithe | déjà le duo |
| Engle–Granger / cointégration | relation long-terme 2 séries ; spread mean-reversion | plus tard (multi-asset / basis) |
| Halo (Lagrange) | moteur de **coordination** swarm : état partagé, consensus, survie si un nœud meurt — *pas* un alpha signal | inspiration **bus duo / watchdog**, pas stratégie prix |

Halo Lagrange = coordination autonome (état partagé, failure detection, pas de chef unique). Chez nous : `duo_state.json` + PID watchdog ≈ version brute du même problème.

## Règle anti-confusion

1. Les pistes vivent **ici**.  
2. Le code / flags / runs vivent dans le brief **amélioration GROK**.  
3. On ne shippe une piste que si elle pousse clairement vers **gros fills ALPHA**, mesurable en CSV.
