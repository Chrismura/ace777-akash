## 📌 RÈGLES D'UTILISATION DU MODÈLE

1. **Un seul format pour tout** — copie ce fichier, remplis, ne change pas la structure.
2. **Numérotation continue** : chaque item garde son numéro d'origine (jamais de renumérotation).
3. **Votes réels** : toujours les 3 votes (Gemini/NIM/juge) dans « Vote final ».
4. **Note Ada** : la tranche sur le fond (ex. « = notre système », « tranche : outils concrets »).
5. **CAPITAL ≠ BRUIT** : la culture va dans CAPITAL (INTERET_PERSONNEL), jamais dans BRUIT.
6. **Le tableau vit** : quand on intègre une idée, on la marque dans le tableau (✅) — on ne crée pas un nouveau fichier.
7. **Statuts possibles** : `I` = INTEGRER · `V` = VERIFIER · `D` = IDEE · `B` = BRUIT · `K` = CAPITAL · `X` = DANGER.
